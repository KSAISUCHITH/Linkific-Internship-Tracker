# Task 3 – Advanced Web & Data Structures

## Task Overview

This task combines web development with data structures and algorithms (DSA) problems. It includes a responsive landing page built with HTML, CSS, and JavaScript, along with Python implementations of classic DSA algorithms.

## Learning Goals

- Master intermediate web development techniques
- Implement fundamental DSA algorithms
- Understand recursion and iterative approaches
- Build interactive web pages
- Create responsive and accessible designs
- Practice algorithm problem-solving

## Components

### Frontend
- **index.html** - Main landing page
- **styles/style.css** - Responsive styling with Flexbox/Grid
- **script/script.js** - Interactive functionality
- **images/** - Visual assets

### DSA - Python Algorithms
1. **Duplicate.py** - Find duplicate elements in an array
   - Uses nested loops to identify and collect duplicate values
   - Input: Array with repeated elements
   - Output: List of duplicate values

2. **Factorial.py** - Calculate factorial using recursion
   - Implements recursive factorial calculation
   - Input: Number from user
   - Output: Factorial result
   - Base case: n=0 or n=1 returns 1

3. **Fibonacci.py** - Generate Fibonacci series
   - Iterative generation of Fibonacci numbers
   - Input: Number of terms in series
   - Output: Fibonacci sequence
